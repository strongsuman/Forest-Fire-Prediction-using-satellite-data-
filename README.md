\# Forest Fire Prediction using Satellite Data



\## Overview

A Machine Learning based Forest Fire Prediction System using NASA FIRMS satellite data for Madhya Pradesh.



\## Features

\- Fire Occurrence Prediction

\- Fire Radiative Power (FRP) Prediction

\- Risk Classification

\- Interactive Dashboard

\- Madhya Pradesh Fire Analysis



\## Tech Stack

\- Python

\- Pandas

\- Scikit-Learn

\-Linear regression

\-Random Forest

\-SVR

\-LSTM

\- XGBoost

\- FastAPI

\- HTML/CSS



\## Dataset

NASA FIRMS Satellite Fire Dataset
